요약 카드와 표 위 도구 막대

관리 화면은 `.stats` 요약 카드(4개, 라벨 아래 숫자) → `.toolbar`(제목·건수 왼쪽, 상태·검색 오른쪽, 라벨은 칸 위) → 표 순서입니다. 건수가 한 화면에 들어오면 페이지 넘김을 생략합니다.

행별 관리 버튼이 2개 이상이면 좁은 화면 카드

`.tbl-wrap--cards`에 `.tbl`과 `.tbl-cards`를 함께 두면 760px 이하에서 표 대신 행별 카드가 보입니다. 이름+보조 줄 칸은 `.stack`, 관리 버튼 묶음은 `.tbl-actions`를 씁니다. 버튼이 하나뿐인 목록은 가로 스크롤 표를 유지합니다.

선택은 실제 일괄 작업이 있을 때 사용

일괄 작업이 도입되는 목록에만 체크박스를 둡니다. 이 사용자 목록처럼 일괄 작업이 없으면 선택 열을 없애고, 각 행의 상세 버튼으로 이동합니다.

날짜와 수치를 구분해 정렬

이름·날짜 같은 정보는 왼쪽, 수치 데이터는 오른쪽에 맞춥니다. 정렬 기능을 도입할 때는 서버 정렬과 키보드·스크린리더 상태까지 함께 구현합니다.
