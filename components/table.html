선택은 실제 일괄 작업이 있을 때 사용

D-ROAD 접속 로그처럼 선택 삭제가 있는 목록에는 체크박스를 둡니다. 이 사용자 목록처럼 일괄 작업이 없으면 선택 열을 없애고, 각 행의 상세 버튼으로 이동합니다.

날짜와 수치를 구분해 정렬

이름·날짜 같은 정보는 왼쪽, 수치 데이터는 오른쪽에 맞춥니다. 정렬 기능을 도입할 때는 서버 정렬과 키보드·스크린리더 상태까지 함께 구현합니다.
