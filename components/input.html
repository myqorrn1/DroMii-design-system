입력 요소

입력·선택·긴 글 입력과 선택 컨트롤의 라벨, 도움말, 오류, 비활성을 비교합니다. 버튼과 같은 높이 단계를 쓰고 제품별 색과 명도만 전환합니다.

라벨은 항상 입력란 위에 둡니다. 플레이스홀더를 라벨로 대신하면 값을 입력한 뒤 무슨 칸인지 사라집니다. 헬퍼 텍스트 자리는 문구가 없어도 16px를 유지해서, 오류가 붙을 때 아래 요소가 밀려나지 않습니다.

입력에는 xs(24)를 쓰지 않습니다 — 아이콘 버튼 전용 높이라 기본 16px 글자가 들어가면 상하 여백이 남지 않습니다.
