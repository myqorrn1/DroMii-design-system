견본 보는 순서

전체 항목은 왼쪽 목록에서 선택
  1. 파운데이션 — 색·글자·간격 등 공통 값
  2. Core 컴포넌트 — 버튼·입력·표·알림의 상태와 동작
  3. 업무 패턴 — 목록·확인·업로드·지도 주변 제어
  4. 제품별 표현 — 같은 Core에 D-FIND 색·표면 적용

제품 적용 전 상태

현재 결과물은 HTML·CSS 견본과 토큰입니다. 공용 React 패키지, 제품별 스타일 매핑과 실제 화면 적용은 다음 작업입니다. 선택형 로그 표는 미사용 API에 근거한 후보이며, 고대비 모드와 실제 스크린리더 검증도 완료로 표시하지 않습니다.
