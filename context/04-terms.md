# 용어 사전

문서와 컴포넌트 설명에 쓰는 한국어 용어를 고정합니다.
새 페이지를 만들 때 **이 표에 없는 말을 지어내지 마세요.**

기준은 **KRDS(대한민국 정부 디자인시스템)** 입니다.
K-AQUAS가 K-water 사업이라 공공 표준에 맞추는 게 유리하고,
KRDS의 원칙 자체가 합리적입니다 —

> 영어 용어를 그대로 두는 이유: **"디자이너와 개발자 모두 이해할 수 있고,
> 보다 직관적이고, 보편적으로 사용되는 용어"** 이기 때문.

즉 **억지로 한국어로 옮기지 않습니다.** 이미 현장에서 통하는 말을 씁니다.

## 색상

| 쓸 말 | 쓰지 말 것 | 비고 |
|---|---|---|
| **강조 색상** | 액센트, 액센트 컬러 | KRDS `Accent = 강조 색상`. 토큰명은 `--dm-accent-*` 유지 |
| **색상 단계** | 램프, ramp | KRDS는 `11단계`처럼 "단계"로 씀 |
| **배경** | 면 | 요소 뒤에 깔리는 색 |
| **표면** | 면 | 카드·모달처럼 떠 있는 판. KRDS `Surface = 표면` |
| **배경 전용** | 식별용 면 | 글자를 얹지 않는 색(500) |
| **글자용** | 글자가 올라가는 면 | 글자를 얹는 색(600) |
| **채움색** | 채움면, solid 면 | 버튼 등의 채워진 배경 |
| **옅은 색 / 옅은 강조 색상** | 틴트 | |
| **보더** 또는 **구분선** | — | KRDS가 둘 다 씀. 토큰명 `border` 유지 |
| **시멘틱** | 시맨틱 | KRDS 표기 |

**상태 색 이름** — 성공 · 정보 · 경고 · 오류
KRDS는 `성공 · 안내 · 주의 · 위험`을 씁니다. 공공 납품 문서를 따로 만들 때는
그쪽에 맞추되, 시스템 내부는 현재 이름을 유지합니다(토큰명이
`success / info / warning / danger`라 대응이 직관적).

## 영문을 그대로 쓰는 것

토큰명 · CSS 속성 · 상태 키워드는 **영문 그대로** 둡니다.
번역하면 코드와 문서가 어긋납니다.

```
hover · focus · pressed · disabled · loading
primary · secondary · ghost · danger
sm · md · lg · xs
z-index · radius · padding · gap
--dm-accent-500 · --dm-surface-card
```

본문에서 언급할 때도 `hover는 중립 한 단계`처럼 영문 그대로 씁니다.

## 서술어 · 표현

용어(명사)만 맞아도 문장이 어색하면 소용없습니다.
아래는 실제로 이 문서들에 쌓여 있던 표현입니다.

| 쓸 말 | 쓰지 말 것 | 왜 |
|---|---|---|
| **임시방편** | 회피책 | `workaround` 직역. 국내에서 안 씀 |
| **더 중요합니다** | 자산입니다 | 비즈니스 번역투 |
| **정해 뒀습니다** | 못 박아 뒀습니다 | 구어적이라 문서에 안 맞음 |
| **섞여 들어온** | 새어 들어온 | `leaked in` 직역 |
| **대신 쓰던** | 빌려 쓰던 | 토큰을 "빌린다"는 은유가 불필요 |
| **임의로 정한 숫자가 뒤엉킴** | 숫자 경쟁 | 뜻이 전달되지 않음 |
| **함께 적용할 기준** | 관통할 기준 | |
| **코드에서 찾은 값** | 발견값 | 조어 |
| **반올림한 값** | 반올림값 | 조어 |
| **이유가 없습니다** | 명분이 없습니다 | 문어투 |
| **중복 묶음** | 중복 덩어리 | |
| **~를 참조한다** | ~를 본다 | 코드 은유 |
| **한 가지 기준으로만 나누면** | 한 축으로 나누면 | 번역투 |
| **자동으로 만들어집니다** | 파생됩니다 | |

**그대로 써도 되는 것** — `얹다` · `파여 보이다` · `답답하다` · `헐거워지다` ·
`걷어내다` · `흔들리다` · `사실상의 기준` · `흡수하다`.
자연스러운 한국어라 굳이 바꾸지 않습니다.

## 확인 습관

- **조사** — 치환 뒤 `옅은 색를`, `딤드은` 같은 오류가 잘 생깁니다
- **중복어** — `강조 색상 색상 단계`처럼 치환이 겹친 자리
- **비문** — `A가 아니라 B가 아닙니다` 같은 이중 부정
- **합성어** — `입력면` `상승면`처럼 `-면`이 붙은 말이 남았는지

## 이 문서가 필요한 이유

v0.11까지 오면서 `면`이 57회, `램프`가 38회, `액센트`가 27회 쌓였습니다.
전부 영어 개념을 그때그때 옮기다 생긴 말이고, 국내 UXUI 현장에서는 통하지 않습니다.

용어가 흔들리면 **같은 것을 두 이름으로 부르게 되고**, 그 순간부터
디자인시스템이 아니라 각자의 문서가 됩니다.
