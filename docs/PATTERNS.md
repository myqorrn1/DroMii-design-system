# 조합 패턴

패턴은 여러 컴포넌트를 실제 업무 순서에 맞게 묶는 기준입니다. 제품마다 데이터는 달라도
같은 종류의 업무가 같은 위치와 동작을 사용하도록 합니다.

## 현재 대표 화면

### 대시보드

현재 포함한 구성은 앱 셸, 핵심 지표 4개, 최근 처리량, 확인할 일입니다.

남은 디자인은 지표 증감 표현, 기간 선택, 차트 툴팁, 데이터 없음, 일부 데이터 로딩 실패,
권한에 따른 카드 숨김입니다.

### 사용자 관리

현재 포함한 구성은 사용자 지표, 검색·상태 필터, 선택 가능한 표, 상태 배지,
페이지네이션입니다.

남은 디자인은 승인·거절·정지·삭제 흐름, 여러 사용자 선택 작업, 권한 편집,
개인정보 마스킹, 빈 결과와 서버 오류입니다.

### 데이터 업로드

현재 포함한 구성은 프로젝트 정보, 촬영일, 설명, 파일 선택 목록, 임시 저장과 분석 시작입니다.

남은 디자인은 대용량 진행 상태, 파일별 검증, 중복 파일, 일부 실패, 재시도, 이탈 경고,
완료 후 다음 행동입니다.

### 지도 워크스페이스

현재 포함한 구성은 앱 셸, 지도 면, 위치 검색, 레이어 선택, 확대·축소·현재 위치,
범례와 저장 동작입니다.

남은 디자인은 레이어 트리, 투명도와 순서, 객체 선택 정보, 측정·그리기, 날짜 비교,
분석 패널, 지도 로딩·타일 오류, 작은 화면에서의 패널 동작입니다.

## 공용 화면 구조

```text
AppShell
├── Sidebar: 주요 업무 이동
└── Main
    ├── Header: 현재 화면 + 전역 동작
    └── Content
        ├── Page title / actions
        ├── Filter or summary
        ├── Primary work area
        └── Feedback / secondary action
```

제품명, 메뉴 내용, 도메인 데이터는 솔루션에서 주입합니다. 위치, 선택 상태, 포커스,
오류 전달과 작업 우선순위는 Core가 정합니다.

## 패턴 추가 기준

1. 한 컴포넌트로 설명할 수 없는 반복 업무인지 확인합니다.
2. 두 솔루션 이상에서 구조가 반복되는지 확인합니다.
3. 정상 흐름뿐 아니라 빈 상태, 오류, 권한 제한, 로딩을 함께 설계합니다.
4. 메뉴와 버튼의 이름보다 사용자의 목표를 기준으로 묶습니다.
5. 대표 화면에 추가해 제품 표현을 모두 확인합니다.
