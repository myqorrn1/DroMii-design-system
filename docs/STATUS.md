# 현재 상태

> 2026-09-23 기준 · v0.15의 확장 검토본 · **DroMii Core 디자인 미완료**

## 현재 결론

K-AQUAS와 D-ROAD의 기존 디자인에서 공통 구조를 추출한 토큰·HTML/CSS 견본·사용 기준이
있다. **Core의 값과 제품별 확장은 아직 확정되지 않았다.** 특히 D-ROAD 운영 React 소스의
전체 실측이 없어 이전 토큰 감사의 일부 근거가 불확실하다. 현재 견본을 바로 제품에
적용하는 React 패키지는 없다. 대표 화면은 소유자가 원하지 않아 제거했으며 이번 범위에서
다시 만들지 않는다.

판단 순서는 [`작업 인계`](HANDOFF.md), KRDS의 채택과 예외는
[`KRDS 채택 범위와 예외`](PUBLIC_SECTOR_DIRECTION.md)에만 기록한다.

## 단계별 상태

| 단계 | 상태 | 결과·다음 조건 |
|---|---|---|
| 0. 미커밋 작업 마무리 | 완료 | 선택형 로그의 가상 검색·선택·삭제 확인, 좁은 유효 화면 대응. `84b8b26` 배포 확인 |
| 1. 방향 문서 재정비 | 완료 | 제품 추출 우선, KRDS 점검 위치와 예외·승인 지점 정리 |
| 2. 운영 소스 재감사 | 다음 | D-ROAD React `src` 전체와 로컬 K-AQUAS 변경분을 같은 항목으로 측정 |
| 3. 매핑·KRDS 대조 | 대기 | `MIGRATION_MAP.md`, `KRDS_ALIGNMENT.md` 작성 후 **소유자 승인** |
| 4. 토큰·파운데이션 | 대기 | 승인값 구현과 전후 비교 후 **소유자 승인** |
| 5. 업무 패턴 | 대기 | 표·검색 → 위험 동작 → 업로드 → 지도 |

## 현재 시각 견본

- 194개 고유 토큰을 가진 제품별 역할 색·표면·글자·간격 후보
- 버튼, 입력, 선택, 배지·칩, 기본 표·페이지 이동·빈 상태, 알림 3종
- 앱 셸·헤더·메뉴, 폼 섹션·저장 상태, 탭·툴팁
- 선택형 로그의 **가상 데이터** 검색, 현재 표시 항목 선택, 삭제 확인·취소·결과

이 견본들은 확정된 컴포넌트 패키지가 아니다. `components/table-selection.html`은
서버 요청 없이 로컬 견본만 변경한다. K-AQUAS·D-ROAD 실제 화면의 오류·권한·부분 성공
동작은 감사와 단계 5 설계가 필요하다.

## 검증한 것과 검증하지 않은 것

- `npm run check`는 토큰 동기화, 참조·링크·라벨·주요 대비 오류를 검사한다.
- 1024·1200·1440·1920px에서는 기존 폼·메뉴·표의 가로 넘침을 확인했다.
- 320px·512px **유효 화면 폭**에서 앱 셸은 세로 재배치되고 표는 내부 가로 스크롤된다.
- 본문 건너뛰기의 Tab·Enter 초점 이동과 가상 로그의 검색·선택·취소·삭제 흐름을
  브라우저에서 확인했다.
- **실제 브라우저 200% 확대**, 모든 컴포넌트의 키보드·스크린리더, 두 제품의
  운영 로그인 후 흐름은 검증하지 않았다. 유효 화면 폭 검사는 확대율 시험이 아니다.

## 제품 감사에서 먼저 확인할 것

- D-ROAD 운영 빌드와 같은 서버의 React 소스 전체: 색, 글자 크기·단위(`vw`), 행간,
  간격, radius, 컨트롤 높이, MUI 사용, 구조·상태·접근성
- K-AQUAS 로컬 프런트의 같은 항목과 이전 스냅샷 이후 변경
- 현재 1열 폼 견본이 실제 제품의 열·순서와 맞는지
- 선택형 로그 삭제의 범위·권한·실패·감사 보존, 사용자 목록 검색·페이지 동작
- 현재 Core 13px과 사용자 요청의 KRDS 17px 대조, D-ROAD 다크 기본값의 실제 범위
