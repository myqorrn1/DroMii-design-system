# 현재 상태

> 2026-10-02 기준 · v0.20 Core 시각·상태 디자인 승인 · D-FIND 제품 표현 확정 · React 내부 패키지

## 현재 결론

K-AQUAS와 D-ROAD의 실제 프런트 코드에서 추출한 공통 형태를 토큰, 공용 CSS,
브라우저 견본과 사용 기준으로 정리했다. 기준색·제공 로고·제품 메뉴와 D-ROAD 다크
기본값을 보존하고 접근성·상태 표현·좁은 폭·긴 내용의 불일치를 리팩토링했다.
KRDS는 [선택한 점검 항목](PUBLIC_SECTOR_DIRECTION.md)에만 사용한다. 고대비 명도는
토큰 구조에 자리만 있으며 아직 선택 가능한 테마가 아니다.

파운데이션과 [공용 컴포넌트 목록](COMPONENTS.md)의 디자인 견본을 구현했다. 다만
**앱 셸·헤더·메뉴는 지도가 주 콘텐츠라는 소유자 피드백에 따라 지도형·관리형
세 제품 통합 배치 검토안으로 재구성했고, 현재 헤더·메뉴·지도 도구·모션 규칙은 소유자가 승인**했다. 기존 248px 고정 메뉴와 안쪽 여백을
지도 업무에 사용하지 않는다.
소유자는 대표 화면을 제외한 Core의 시각·상태 디자인을 승인했다. D-FIND는 제공된
프론트의 색·표면을 사용하고 기존 흰색 primary 버튼을 유지하기로 결정했다. 이 결정은
운영 화면 검증, 앱 셸 승인, 실제 제품 적용이나 API 검증을 뜻하지 않는다. 도메인 대표 화면은
만들지 않는다. 제품별 유지·변경 기준은 [적용 가이드](APPLICATION.md)에 정리했다.

2026-10-01 소유자 요청으로 공통 앱 셸보다 **로그인·회원가입 통일을 먼저** 진행한다.
[세 제품 인증 시안](../components/auth.html)을 바탕으로 소유자가 React 구현을 요청해
인증 조합 v0.3.0을 만들었다. 실제 계정 정책·제품 코드 연결은 별도 단계다.
이후 소유자가 통합 플랫폼 추천 배치를 승인해 [통합 셸 검토안](../components/navigation.html)을
구현했다. K-AQUAS는 추가 요청에 따라 기존 업무 메뉴 전체·관리 3종과 가상 작업 배치까지
확장했다. 후속 결정으로 Home 메뉴·가상 홈은 제거했고, 홈은 기존 MainPage를 쓰며
사이드메뉴는 제품 원본 아이콘을 유지한다. 최신 요청에 따라 카테고리별 기존 내부
배치·하단 실행·지도 위 제어를 복원하고 Core 표현만 적용했다. 헤더·메뉴·지도 도구·모션의 승인된 시각 기준을 사용하며 React 셸·제품 적용은 아직 없다. 상세 배치와 제품 차이는 [시각 규칙](VISUAL_STYLE.md#앱-셸의-공통-규칙)을 따른다.

## 남은 확인과 적용

1. 인증 React 구현은 완료했다. 승인된 셸 스타일은 세 제품 HTML에 반영했다.
   D-ROAD·D-FIND의 새 패널 시안을 검토한 뒤 React 셸 조합을 구현한다. D-FIND 운영 화면, 실제 라우팅·권한·SSO는 미확인이다.
2. 확대된 견본의 주요 조작은 확인했지만 전체 키보드 경로, 실제 스크린리더 발화와
   운영 제품의 대표 업무 흐름은 확인하지 않았다. 접근성 최종 판정과 구분한다.
3. 서버 응답·권한·삭제 정책·실제 업로드 결과는 제품 연동 때 검증한다. D-ROAD
   일괄 삭제 API는 현재 화면에서 쓰이지 않으며, 파일별 부분 성공·수치 진행률은
   두 제품에서 확인된 동작이 아니다.
4. D-FIND의 제공 소스 기준 제품 표현은 정리했다. 운영 화면의 실제 계산 스타일과
   데이터는 적용 시 다시 확인한다. 지도 유리 패널·보고서 인쇄 스타일은 제품 확장이다.
   고대비 테마와 Combobox는 사용 근거·별도 결정이 있을 때 설계한다. 제품 코드 변경은
   이번 범위 밖이다.
