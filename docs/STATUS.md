# 현재 상태

> 기준 버전: v0.15  
> 기준일: 2026-09-11  
> 단계: DroMii Core 1차 디자인 후보

## 현재 결론

디자인 방향과 대표 구조는 정해졌지만 **디자인 자체는 아직 완료되지 않았습니다.**
현재는 K-AQUAS와 D-ROAD에서 공통으로 쓸 시각 언어를 확인하고, 주요 화면에 조합해
볼 수 있는 단계입니다.

전체 목표를 나눠 보면 다음 정도입니다.

- 디자인 기준과 시각 견본: 약 60~65%
- 토큰 관리 기반: 약 70%
- 실제 React 컴포넌트: 시작 전
- 제품 적용: 사용자 요청에 따라 보류

이 수치는 일정 산정을 위한 대략적인 상태이며 완료 판정은 아래 체크리스트로 합니다.

## 완료된 디자인

### 파운데이션

- K-AQUAS와 D-ROAD 기준색을 유지한 역할 중심 색상 체계
- 라이트·다크 표면, 텍스트, 보더, 상태, 포커스 역할
- Pretendard 중심 글자 체계와 데이터용 모노스페이스
- 간격, radius, 컨트롤 높이, 엘리베이션, z-index
- 데스크톱 1440px 기준과 1024px 축소 동작
- 제품별 차트 계열 6색
- 반복 업무용 Core 아이콘 12개

### 컴포넌트

- 버튼과 아이콘 버튼
- 텍스트 입력, 셀렉트, 텍스트 영역
- 체크박스, 라디오, 스위치
- 상태 배지와 필터 칩
- 데이터 테이블, 행 선택, 페이지네이션, 빈 상태
- 토스트, 배너, 다이얼로그
- 앱 셸, 헤더, 사이드 메뉴
- 폼 섹션과 작업 버튼 배치
- 탭과 툴팁

### 조합 화면

- 대시보드
- 사용자 관리
- 데이터 업로드
- 지도 워크스페이스
- 같은 구조의 K-AQUAS·D-ROAD 표현 전환

## 디자인 확정 전에 남은 작업

### 우선순위 1 — Core 범위 완성

- 토큰을 reference, semantic, component 계층으로 완전히 분리
- 브랜드, 명도, 밀도를 서로 독립된 설정으로 정의
- 검색 입력, 비밀번호 입력, 콤보박스, 메뉴, 날짜 선택의 상세 상태
- 로딩, 진행률, 업로드 실패·재시도·부분 성공 상태
- 선택 항목 작업 표시줄과 위험 동작 확인 흐름
- 드롭다운, 브레드크럼, 아코디언, 인라인 오류의 포함 여부 확정
- 텍스트 링크, 구분선, 카드, 섹션 헤더의 정식 기준

### 우선순위 2 — 핵심 업무 패턴 완성

- 사용자 승인·거절·정지·삭제 흐름
- 업로드 대기·진행·완료·실패·재시도 흐름
- 지도 레이어, 범례, 도구 모음, 객체 선택, 정보 패널
- 차트 범례, 툴팁, 임계값, 시계열, 데이터 없음 상태
- 긴 표의 고정 헤더, 가로 넘침, 선택, 페이지 이동 조합
- 화면 전체 로딩, 권한 없음, 네트워크 오류, 데이터 없음

### 우선순위 3 — 시각 확정과 문서화

- K-AQUAS와 D-ROAD 대표 화면에 같은 Core를 대입한 최종 교차 검토
- 1024·1200·1440·1920px 화면 폭 검토
- Core 아이콘 확대와 수질·도로 도메인 아이콘의 경계 확정
- 제품별 허용 변경과 금지 변경 확정
- 컴포넌트별 좋은 사례, 잘못된 사례, 문구 기준 보강
- 모든 미결정 항목의 승인 상태 기록

## 현재 보류한 작업

- K-AQUAS, D-ROAD, D-FIND 실제 코드 적용
- React 공용 패키지 배포
- 기존 화면 마이그레이션
- 운영·스테이징 배포

위 작업은 디자인 확정 이후 진행합니다.
