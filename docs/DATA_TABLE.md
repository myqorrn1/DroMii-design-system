# 데이터 테이블 — Core 1차 기준

시각 견본: [기본 표](../components/table.html),
[선택형 로그 표](../components/table-selection.html).

## 기본형

- 열 이름은 짧고 구체적으로 쓴다. 각 행의 값은 열 이름만으로 이해할 수 있어야 한다.
- 이름·날짜·상태 등 텍스트는 왼쪽, 비교할 수치값은 오른쪽에 정렬한다. 날짜는 연도를
  포함해 같은 형식으로 표시한다.
- 행 전체를 클릭 대상으로 만들지 않는다. 상세 보기나 수정은 행 안의 명시적인 링크·버튼으로
  제공하고, 반복 버튼에는 대상 이름을 접근 가능한 이름에 포함한다.
- 페이지 이동은 현재 페이지를 문자와 `aria-current="page"`로 표시한다. 비활성 이전·다음
  버튼은 실제 범위에 맞춰 갱신한다.
- 데이터가 전혀 없는 상태와 검색 결과가 없는 상태를 구분하고, 각각 다음 행동을 제시한다.

## 선택형 목록의 경계

사용자 관리 견본에는 실제 일괄 작업이 없으므로 선택 열을 두지 않는다. D-ROAD의
접속 로그처럼 선택 작업이 필요한 목록에는 체크박스·선택 건수·수행할 작업·확인 단계와
결과를 한 패턴으로 둔다. 전체 선택의 범위는 반드시 현재 페이지 또는 현재 표시된 결과 등
구체적인 이름으로 알려준다. 현재 선택형 로그 견본은 **가상 데이터의 로컬 동작**만 제공한다.
서버의 부분 실패·감사 보존·권한 규칙은 아직 구현하거나 검증하지 않았다.

검색 조건이 바뀌면 선택을 초기화한다. 일부 행만 선택되면 전체 선택 체크박스는 혼합 상태로
표시하고, 선택이 0건이면 일괄 작업 영역을 숨긴다. 삭제처럼 되돌릴 수 없는 동작은 대상
건수를 보여주는 확인 다이얼로그에서 실행한다. 취소 시 선택과 초점을 유지하고, 실행 결과는
목록 가까이에 알린다. 세부 검색 규칙은 [`목록 검색·필터`](LIST_FILTER.md)를 따른다.

좁은 유효 화면에서는 표 자체를 줄여 글자를 세로로 쪼개지 않고 가로 스크롤한다. 스크롤
영역을 키보드로 찾을 수 있게 이름과 초점을 제공한다. 검색·정렬·페이지네이션의 서버
동작은 각 제품의 API와 맞춰야 한다.

## 공공업무 기준

[KRDS 테이블](https://www.krds.go.kr/html/site/component/component_04_11.html)의
열 최소화, 데이터 유형별 정렬, 명시적 조작 요소를 기본 기준으로 삼는다. 전문 업무에서
고정 열·가로 스크롤·높은 밀도가 필요하면 읽기 순서, 헤더 연결, 키보드 이동을 함께 검증한다.
공식 정부 서비스의 규정 준수 판정이나 접근성 인증을 의미하지 않는다.

## 남은 검증

- 실제 브라우저 200% 확대, 고정 헤더·열과 표 내부 가로 스크롤
- 긴 이름, 빈 값, 단위가 있는 수치, 오류·권한 제한 행의 표시
- 실제 D-ROAD 선택 삭제의 권한·실패·감사 보존과 K-AQUAS 관리 목록의 조작 방식 교차 검증
