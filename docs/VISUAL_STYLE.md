# DroMii Core 시각 스타일 — 1차 기준

> 2026-09-23 기준. 대표 화면을 만들기 전, 공통 요소에서 먼저 검토할 스타일이다.
> 근거: [`운영 프론트 재확인`](../context/05-live-frontends-2026-09-23.md).

> 2026-09-29 재검토: [두 운영 화면의 실측](../context/06-product-audit-2026-09-23.md#2026-09-29-핵심-업무-화면-후속-확인--읽기-전용)을
> 반영해 지도형과 관리형 셸을 별도 견본으로 만들었다. 소유자 검토 전 설계안이다.

## 목표

K-AQUAS와 D-ROAD가 서로 다른 색과 명도로 보여도 헤더, 메뉴, 글자 위계, 컨트롤의
형태와 상태를 보면 같은 DroMii 제품군으로 읽히게 한다. 공공기관 실무자가 지도·표·폼을
오래 사용하는 업무 도구이므로 데이터, 현재 작업, 처리 결과가 장식보다 먼저 보이게 한다.
KRDS 채택 범위와 예외는 [`KRDS 채택 범위와 예외`](PUBLIC_SECTOR_DIRECTION.md)에
기록한다.

## 공통 인상

- **표면:** 페이지·패널·떠 있는 면을 역할별로 구분한다. 일반 영역은 얇은 경계선으로
  나누고, 그림자는 떠 있는 요소에 집중한다. 큰 카드나 색 면으로 화면을 채우지 않는다.
- **글자:** Pretendard를 기본으로, 제목·본문·보조 정보의 위계를 반복한다. 숫자가 많은
  표·지표에는 데이터용 모노스페이스를 쓸 수 있다. 글자 크기를 뷰포트 `vw`로 정하지 않는다.
- **형태:** 작은 컨트롤에는 4px, 큰 떠 있는 면에는 10px 반경을 기본으로 한다.
  임의의 각진/둥근 형태를 화면마다 섞지 않는다.
- **간격:** 기존 4px 단계와 24px 본문 여백을 기본으로 하고, 조밀한 지도 도구는
  별도 밀도 설정을 사용한다. 내용이 많다는 이유로 글자를 작게만 줄이지 않는다.
- **강조:** 제품 기준색은 주요 실행, 현재 위치, 포커스처럼 의미가 있는 곳에 사용한다.
  메뉴마다 색을 따로 주거나 넓은 배경을 기준색으로 칠하지 않는다.

## 앱 셸의 공통 규칙

1. 지도형 셸은 **작업 패널·지도 캔버스·지도 위 제어**를 공통 구조로 쓴다. 지도에는
   카드형 본문 여백을 두지 않는다. K-AQUAS의 기능 레일·지도 위 맥락 카드와
   D-ROAD의 상단 바·지도 아래 결과 줄은 제품별 구성으로 둔다.
2. 제품 식별과 현재 업무 맥락은 두 제품에 모두 보이되 같은 위치의 전체 폭 헤더를
   강제하지 않는다. 제공된 가로형 SVG 로고를 사용하고 로고 재설계는 제외한다.
3. 좌측 작업 패널은 현재 기능의 필터·목록 또는 프로젝트 계층을 담는다. 접을 때
   계층을 아이콘으로 축약하지 않고 지도를 넓히며 명확한 다시 열기 제어를 남긴다.
   관리형 셸은 별도 변형으로 두고 제품의 관리 메뉴 구조를 주입한다.
4. 현재 위치는 **강조색만이 아니라** 굵기와 선택 표시로 드러낸다. hover는 중립 표면,
   현재 위치는 옅은 강조 표면과 좌측 표시를 함께 사용한다.
5. 아이콘은 기존 Core 선형 아이콘 기준을 따른다. 실제 업무를 설명하지 못하는 장식
   이모지를 메뉴 아이콘으로 사용하지 않는다.
6. 헤더와 메뉴는 실제 링크·버튼으로 구성한다. 계정 메뉴는 펼침 상태와 키보드 접근을
   명시한다. 알림 개수는 숫자와 접근 가능한 이름으로 전달한다.
7. 키보드 사용자가 반복 탐색을 건너뛰도록 본문 건너뛰기 링크를 제공한다. 로고에는
   제품명을 대체 텍스트로 제공한다.

지도 견본의 패널 펼침 폭은 K-AQUAS 280px, D-ROAD 320px이다. 이는 각각 운영
화면의 280px과 약 250~326px을 바탕으로 한 **검토값**이다. 관리형 견본의 기존
56px 헤더·248px 메뉴도 시각 규칙을 비교하기 위한 값이며 제품을 그대로 복제한
것이 아니다. 모든 셸 치수는 소유자 검토 후 확정한다.

## 솔루션 설정

| 설정 | K-AQUAS 기본 | D-ROAD 기본 | Core에서 고정할 것 |
|---|---|---|---|
| 기준색 | 기존 파랑 `#5098EC` | 작업 화면의 기존 보라 `#9D91FF` | 색이 쓰이는 역할과 대비 |
| 명도 | 라이트 | 다크 기본값 유지 | 표면의 역할과 위계. 고대비는 별도 예약 축 |
| 밀도 | 기본 16px, 좁은 지도 패널 compact 14px | 기본 16px, 좁은 데이터 패널 compact 14px | 40/44px 일반 제어, compact 32px, 24px 아이콘 전용 |
| 탐색 내용 | 댐·수질·관리 업무 | 데이터셋·프로젝트·관리 업무 | 메뉴 행의 형태·상태·키보드 동작 |

색상 원본은 [`tokens/source.json`](../tokens/source.json)이다. 이 문서는 색상 값을
중복 관리하지 않고 현재 기준색과 사용 원칙만 설명한다.

## 검토 순서

1. 헤더와 메뉴의 라이트·다크, 선택·hover·focus·disabled, 긴 이름과 좁은 폭을 확인한다.
2. 버튼·폼·알림·표에 같은 글자 위계와 표면 규칙을 적용한다. 폼의 섹션·오류·저장 상태는
   [`폼 레이아웃`](FORM_LAYOUT.md)에서 관리한다.
3. 지도·차트·업로드의 업무 상태를 설계한다.
4. Core와 솔루션별 확장이 확정되면 대표 화면을 다시 제작한다.
